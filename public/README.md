# Aerovian Airways — Full-Stack Website

A polished airline website built with HTML, CSS, vanilla JavaScript and a Node.js/Express backend.

## Included
- Responsive airline homepage
- Flight search UI
- Booking form and booking API
- Contact form API
- Newsletter signup API
- Fleet, hubs, routes and travel-experience sections
- Mobile navigation
- Accessibility-minded semantic HTML
- Simple JSON persistence in `data/`
- Health-check endpoint

## Run locally
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Visit `http://localhost:3000`.

## Important
The booking/search backend is a working demo backend with local JSON storage. It is **not connected to a real airline reservation system, payment processor, airport inventory, or GDS**. For production, connect the API layer to your actual reservation/GDS provider, payment gateway, authentication, email provider, database, monitoring, and security controls.
